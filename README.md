# Scribe

A browser-based novel-writing app.

- **Left:** a tree of folders and pages. Drag to reorder or move items into folders; double-click (or F2) to rename; Del to delete.
- **Right:** a Courier, double-spaced editor for the selected page.
- Work autosaves to the browser's localStorage. Use **Export / Import** in the sidebar footer to back up or move a project as JSON.

```sh
npm install
npm run dev
```
